# AstrBot 长期记忆插件

把仿人脑分层记忆系统接入 AstrBot，让机器人拥有可衰减、可复习、可遗忘的长期记忆。零第三方依赖。


## 聊天指令

| 指令 | 作用 |
|---|---|
| `/记住 我只喝美式咖啡` | 保存记忆（S2 层） |
| `/永久记住 我对海鲜过敏` | 钉住，永不衰减、永不自动删除 |
| `/回忆 咖啡` | 手动检索记忆 |
| `/记忆列表` | 查看所有记忆与 id |
| `/忘掉 mem_xxx` | 软删除（30 天内可恢复） |
| `/记忆统计` | 各层数量统计 |

## 自动行为

- **自动回忆**：每轮对话请求 LLM 前，自动检索与当前消息相关的记忆，注入 system prompt（上限 1500 字，钉住记忆优先）。
- **自主记忆**：注册了 `remember_memory` / `forget_memory` 两个 LLM 工具，模型判断用户说出稳定事实或要求遗忘时会自行调用（需模型支持工具调用）。
- **每日归档**：插件每 24 小时自动执行衰减归档，低强度记忆降层，跌破阈值进回收站。

## 说明

数据保存在 AstrBot 插件数据目录下（`StarTools.get_data_dir()/memory`），原文为 Markdown，可用记忆系统主程序直接管理。
